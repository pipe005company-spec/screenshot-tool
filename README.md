# 📸 Enoch Screenshoter

A simple yet interactive Python screenshot application built with `pyscreenshot`.

## ✨ Features

- Capture full screen instantly
- Preview screenshot before saving
- Save with custom filename
- Input validation for filename
- Interactive yes/no flow control
- Error handling for invalid inputs
- Clean user interface

## 🛠️ Technologies Used

- Python 3
- pyscreenshot library

## 🚀 How to Use

1. Run the script
2. Choose "yes" to capture screenshot
3. Optionally view the screenshot
4. Save with your preferred filename

## 📦 Installation

```bash
pip install pyscreenshot
python screenshot_app.py
